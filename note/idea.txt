## 基于特征点动态性评分的轻量级动态点剔除方法构想

### 背景与动机

在动态环境中，视觉SLAM系统常因特征点落在动态物体（如人、车）上而产生误配，导致位姿估计不准确。现有主流方法如 DynaSLAM、DS-SLAM 等通常依赖于语义分割或实例分割（如Mask R-CNN）来检测并剔除动态区域。

但这些方法存在以下问题：

- 高计算成本；
- 对分割精度强依赖；
- 无法适应未标注类别或伪静态目标；
- 实时性不佳，难以部署到轻量级平台。

### 核心思想

训练一个点级别模型，仅利用局部信息对特征点的“动态性”进行评分，而非显式对图像进行分割或检测。

- 不进行大规模分割推理；
- 不依赖明确语义标签参与前端处理；
- 用模型判断特征点是否参与前端匹配。

### 数据集构建

#### 按照对象

基于现有图像识别等任务数据集，使用特征点提取算法获取特征点作为训练数据；借助已有的分割工具（如 Mask R-CNN）对图像进行分割，结合语义类别对特征点打分作为标签：

| 分数范围 | 示例语义         | 解释                       |
| -------- | ---------------- | -------------------------- |
| 1.0      | 墙、地板、天花板 | 永久静态，高置信度参与SLAM |
| 0.6–0.9  | 桌子、椅子、沙发 | 结构静态，但可能被移动     |
| 0.3–0.5  | 静止人、车等     | 有潜在运动风险             |
| 0.0–0.2  | 活动人、车等     | 高动态目标，排除           |

#### 按照动态

基于提供三维运动信息的数据集，如Object Scene Flow，提取特征点作为训练数据；将特征点所属的对象的移动与否作为标签。

### 模型设计

#### 1.  输入

- 特征点 patch 图像块；
- 局部梯度/纹理（可用 CNN 或 Sobel filter 提取）；
- 光流残差（或帧间图像差）。

#### 2.  网络结构

- Patch 输入 → 卷积提取局部上下文；
- 多尺度融合（提升鲁棒性）；
- 全连接输出静态性分数 ；
- 使用 attention / GNN 加强点间关系建模。

### 系统设计

在ORB_SLAM3的基础上添加一个特征点筛选线程，尽可能提高并行化程度。

1. **语义筛选**：
   用点评分模型根据阈值剔除潜在动态点，仅保留语义静态点。

2. **初步位姿估计**：
   在语义静态点随机选择足够数量的点进行初步相机位姿估计。

3. **动态点判定**：
   用初始位姿 + 深度计算预测光流，与实际光流对比，添加几何静态点。

4. **静态点可靠性验证**：

   通过重投影验证其他语义静态点是否可靠，剔除不可靠的语义静态点。

5. **随机采样一致性**：

   重复2到4步多次，选择使得静态点最多的模型。

4. **精确位姿优化**：
   使用最终的“真实静态点“重新估计相机位姿，进行地图更新。

### 其他策略

- 多帧时序一致性判断；
- 使用投影残差/几何一致性 refine 标签；
- 利用 tracking 或伪标签学习动态概率。

### 意义

- 预期中模型推理效率更高；
- 点级别的模型在这个应用场景下没有性能溢出；
- 有一定处理训练数据中没有出现过的对象的能力。





## 基于增量学习模板的语义建图

### 一、研究问题

研究一种具备**自适应能力**的语义对象建图方法：系统在识别语义标签的基础上，根据实际环境中观测到的几何信息，**自动调整预存的语义对象模板**，从而更加准确地将对象插入到语义地图中。

我们希望该系统具备以下能力：

1. 自动匹配并调整语义对象模板；
2. 从历史观测中学习几何变化的规律；
3. 增量更新模板模型，提高泛化能力；
4. 在不显著增加计算负担的前提下实现高质量建图。

### 二、流程设计

#### 1. **语义识别与配准**

- 使用现有目标检测/分割网络（如Mask R-CNN）获取语义标签和粗位姿；
- 提取观测点云，通过刚性ICP / 非刚性ICP 与模板对齐；
- 得到配准变换（R, t）或形变字段。

#### 2. **模板变形与配准结果收集**

- 保留每一次配准后的变形模板（可通过应用变换到原始模板得到）；
- 建立一个历史模板变形序列。

#### 3. **增量模板更新机制**

- 对历史变形结果进行聚类或平均操作（如Karcher均值、点云平均）；
- 或者构建低维形状空间，对变形结果做PCA降维并更新均值模板；
- 每当一个对象类累积足够样本后，更新该类别的“当前模板”。

#### 4. **地图构建**

- 使用最新模板（经变形）插入地图；
- 将背景使用传统方式建图，前景对象用更新后的实例模板替代原始几何。







## 全流程语义增强的ORB-SLAM系统

###  简介

在 ORB-SLAM3 的基础上，引入语义信息参与各核心模块，包括跟踪、建图、优化与回环，从而实现一个具备结构理解能力、鲁棒性更强的视觉 SLAM 系统。

###  模块设计

#### 1. 动态特征点剔除

**目标**：剔除来自“动态/半动态”物体上的特征点，防止错误估计与漂移。

**方法**：

- 使用轻量级语义分割网络；
- 标记出动态类；
- 结合几何信息进行验证；
- 剔除动态特征点。

**参考**：RSO-SLAM，MVS-SLAM

#### 2. 语义地图构建

**目标**：为地图点添加语义标签，构建**语义层级地图**。

**实现方式**：

- 每个地图点携带其观测帧对应像素的语义标签；
- 构建：
  - 点云级语义地图；
  - 稀疏结构语义地图；
  - 基于CAD的语义地图。

**参考**：QuadricSLAM、CubeSLAM、Scan2CAD

#### 3. 语义增强的 BA 优化

**目标**：将语义结构先验或物体模型引入 BA 优化，提升鲁棒性。

**思路示例**：

| 类型         | 误差项表达                     |
| ------------ | ------------------------------ |
| 尺度一致性   | 点所属类别的物体应满足尺寸约束 |
| 结构模型约束 | 点应落在已知的语义结构模型上   |
| 位姿关系先验 | 同类物体之间保持相对位置稳定   |

**参考**：CubeSLAM

#### 4. 语义增强的回环检测

**目标**：提高回环匹配阶段的判别能力，防止错误闭环。

**参考**：学长的工作
